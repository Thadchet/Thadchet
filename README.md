### What I'm building

**[Kubehack](https://github.com/Thadchet/kubehack)** is a Kubernetes desktop app for
macOS, Windows and Docker. Browse resources, follow logs, open shells, forward ports
and manage Helm releases, using the kubeconfig you already have.

```sh
brew tap thadchet/tap && brew trust thadchet/tap && brew install --cask kubehack
```
